Mapper vs python -m engine run Prefer python vc_mapper.py for VC solutioning. python -m engine run is the older/parallel full staffing path that produces Excel + Deal_Output.json.

Preferred for this kit

python vc_mapper.py

Template → Mapped_Sites / Summary / Cost_Model_Load. Then bridge helper or sandbox JSON → cost model. Use for new VC solutioning.

Older / parallel

python -m engine run

Full deal-engine path in engine/: intake → Excel + Deal_Output.json → upload on /cost-model. Optional when you need locked day-one staffing.

Sandbox browser catchment mirrors mapper-style roles — it does not replace a full engine run for cash/OEM workbook depth.
