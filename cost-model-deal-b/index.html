Model logic (the defensible version)

Demand and staffing
  • Tickets/yr = users x tickets-per-user. Deflection% removes tickets before staffing (self-service + remote-first).
  • When the Deal B summary is loaded, day-one technicians and tech-bar count come from the pattern (dedicated bar techs + virtual + roving). Manual Inputs remain a scenario sandbox.
  • Without a summary file, day-one technicians ≈ ceil(daily walk-in tickets / walk-in rate / utilization) + ceil(daily virtual tickets / remote rate / utilization), floored by bars × floor.
  • Road-map rungs: technicians = max(bars × floor, ceil(users / ratio)). Tech-bar ratios (~1500:1–2000:1) are commercial guardrails. Leads = ceil(techs/lead span); managers = ceil(techs/mgr span).
  • Blended tech rate = regional mix-weighted salary x (1 + burden). This example is NAM-heavy. Leads at premium x blended; managers flat + burden.
Logistics, dispatch and OEM (the shift)
  • Physical touches = adjusted tickets x physical-touch share. Staff on-site capacity = techs x on-site allocation (60% of capacity) x rate x days x utilization.
  • Uncovered touches = max(0, touches - staff capacity): break-fix share of those goes to OEM warranty at attach% (per-event cost), the rest to smart-hands dispatch (per-visit cost).
  • Parts shipments = parts share of physical touches, costed per shipment; depots carry fixed + per-shipment variable; campus stock value x carrying% is inventory cost, scaled down as headcount consolidates (stock follows staffed footprint at 40% elasticity).
  • Device refresh = users x devices per user / refresh cycle. Zero-touch maturity% of refreshes ship direct (shipping only); the rest incur a touch cost plus shipping.
Transition and cash
  • Each step: exits x severance + hires x hire/training + parallel-run months x (old monthly labor x 25% overlap) + program management.
  • Cash view: each year charges the annual cost of the active rung plus any step one-time; cumulative line compares against staying at current state.
