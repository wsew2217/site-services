First pilot checklist

Condensed build order and acceptance criteria for the assembled solutioning kit. Customer pilots stay on Desktop — off git.

Build waves

W1
Workbook

Create / refresh vc_template_pack_v1_0.xlsx

W2
Python package

requirements.txt, rules YAML, vc_mapper.py, README

W3
Sample run

Map starter rows; review Exceptions → Summary → roles → Cost_Model_Load

W4
SalesChat pack

Paste agent texts (UI publish is manual)

W5
Governed folders

Templates / rules / customer inputs / outputs / exceptions / overrides

W6
Pilot

Desktop customer run, issue log, override tracking

Before / during / after first run

  • Template workbook exists
  • Python files + venv deps installed
  • Input populated (generic starter or Desktop pilot)
  • Mapper executes without crash
  • Exceptions inspected first
  • VC_Mapped_Sites roles look coherent
  • VC_Summary role split recorded
  • Cost_Model_Load ready for bridge / engine
  • Issues documented; rerun after source fixes
  • Approved outputs archived under governed folders

Acceptance — first assembled version

Version one exists when all of the following are true:

  • Workbook template physically created
  • Python package physically created and runnable
  • Mapper produces an output workbook
  • SalesChat agent texts configured in the UI (manual)
  • Governed folder structure exists on Desktop
  • At least one governed pilot run completed (customer data off git)
