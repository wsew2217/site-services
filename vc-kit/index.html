Preferred for this kit

python vc_mapper.py

VC kit mapper: vc_template_pack → Mapped_Sites / Summary / Cost_Model_Load. Then bridge helper → cost model. Use this for new VC solutioning.

Older / parallel path

python -m engine run

Deal engine in engine/: intake template → Excel + Deal_Output.json → upload on /cost-model. Full staffing / VC pipeline — not required to start mapping.

Plain English: map roles with the kit first; use the engine when you need a full deal staffing pass and Engine JSON for the cost sandbox.
