Mac setup & run Create a venv, install requirements, then run vc_mapper.py with --input and --output. Add --skip-geocode if lat/lon are already filled. 

cd ~/Desktop/site_services_vc_mapper   # or: cd tools/vc_mapper in this repo
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install --upgrade pip
pip install -r requirements.txt

python3 vc_mapper.py \
  --input vc_template_pack_v1_0.xlsx \
  --output vc_template_pack_v1_0_mapped.xlsx \
  --operator-name "Your Name"

# Optional when lat/lon already present:
python3 vc_mapper.py --input … --output … --operator-name "…" --skip-geocode

Cost_Model_Load → engine / cost page After mapping: bridge to Sites xlsx / JSON. Bridge JSON is approximate. For locked day-one techs, run the deal engine on the bridged Sites file, then upload Deal_Output.json.

  1. Review Exceptions, then roles on VC_Mapped_Sites / VC_Summary
  2. Export Sites intake: python3 cost_model_bridge.py --input mapped.xlsx --sites-out engine_sites.xlsx --json-out bridge.json
  3. Optional full staffing: python -m engine run engine_sites.xlsx -o Deal_Output.xlsx
  4. Load Deal_Output.json (or bridge JSON for a rough sandbox) on /cost-model

Bridge JSON is approximate — day1_techs_hint is not final staffing. Preferred kit path is mapper → bridge; engine run is the parallel full-pass option.
