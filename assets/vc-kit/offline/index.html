Pipeline how-to

0
One-click sandbox (browser) — On the live site open /sandbox and click Try sample deal (or upload Excel). Catchment runs in-browser → sessionStorage → map / /cost-model?from=sandbox / proposal pack. Gap: not a full python -m engine run (no full cash/OEM workbook).
1
Template — Fill VC_Site_Input_Template in vc_template_pack_v1_0.xlsx (one row per site; country + a demand signal required).
2
Mapper — Run python vc_mapper.py with default_rules.yaml → Hub / Local / Remote on VC_Mapped_Sites plus Summary, Cost_Model_Load, Exceptions.
3
Cost_Model_Load — Engine-aligned bridge sheet. Review Exceptions first. Not a priced proposal by itself.
4
Cost model — Bridge helper → Sites intake / JSON → optional full engine run → upload Deal_Output.json on the cost-model sandbox (or use Export HTML report / proposal pack there).
Also on the live suite: How to use this site, /vc-kit/chat (offline FAQ or live AI Gateway), scenario compare strip on /cost-model and sandbox results, proposal export zip (Site_Services_Proposal_Pack_<timestamp>).

Two tools — which one?

Preferred for this kit

python vc_mapper.py

VC kit mapper: template → Mapped_Sites / Summary / Cost_Model_Load. Then bridge helper → cost model. Use this for new VC solutioning.

Older / parallel path

python -m engine run

Deal engine in engine/: intake → Excel + Deal_Output.json → cost-model upload. Full staffing / VC pipeline — not required to start mapping.

Mac setup & commands

Setup

cd ~/Desktop/site_services_vc_mapper
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install --upgrade pip
pip install -r requirements.txt

Run mapper

python3 vc_mapper.py \
  --input vc_template_pack_v1_0.xlsx \
  --output vc_template_pack_v1_0_mapped.xlsx \
  --operator-name "Your Name"

Optional: --skip-geocode when lat/lon already present. Rebuild template with python3 build_template.py.

Bridge to Sites / JSON

python3 cost_model_bridge.py \
  --input vc_template_pack_v1_0_mapped.xlsx \
  --sites-out engine_sites.xlsx \
  --json-out bridge.json

Catchment rules (v1)

  • Local range: ≤ 25 mi OR ≤ 60 min drive proxy @ 40 mph
  • Near a Staffed campus → always Local
  • Remote only if far and tickets/day < 1.2
  • Far and ≥ 1.2 tpd → Staffed campus
  • Hub selection priority: tickets → users → seats; hub threshold 3.0 tpd
